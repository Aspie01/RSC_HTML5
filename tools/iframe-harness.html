Cross-origin embed harness

This page is served from a different port, and therefore a different origin, than the game inside the frames. That is the arrangement on itch.io, and it is the one that breaks builds which work when opened directly. The two frames differ only in their sandbox attribute: the first can reach storage, the second cannot, which is how a player with blocked cookies arrives. The second should still be playable and should say so.

1. Sandboxed, storage allowed

sandbox="allow-scripts allow-same-origin allow-popups allow-forms allow-modals"

2. Sandboxed, storage denied

sandbox="allow-scripts allow-modals" — no allow-same-origin
